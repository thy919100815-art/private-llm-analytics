## 2. Re-generating $N=100,000$ Dataset (Single Command)

To regenerate `interactions_n100000.parquet` bit-for-bit with matching SHA-256 hash:

```bash
python -c "from private_llm_analytics.simulator.generator import SyntheticDataGenerator; from private_llm_analytics.simulator.scenario import SimulationScenario; gen = SyntheticDataGenerator(SimulationScenario(n_users=100000, random_seed=42)); gen.generate_and_save('data/interactions_n100000.parquet')"
```

All experimental results, summary tables (`results/tables/scalability_benchmark.csv`), and 500-trial data (`results/raw/exp03_population_trials.csv`) for $N=100,000$ are retained in the project distribution.
