90 天 Privacy Epoch 与 Workload Budgeting 架构说明

固定 90 天 Privacy Epoch + 任务预算分配（Workload Budgeting）：

单任务 RDP 矢量: ρi(α) = α Δ2,i2 / (2 σi2)
Epoch 累计组合约束: ∑i ρi(α) ≤ Repoch(α)
转换最终有效预算: εepoch(δ) ≤ 4.0000 (δ = 1e-6)
  • 优先级 1（缓存命中）：相同 ReleaseKey 重复发布直接复用，严格消耗 0 预算。
  • 优先级 2（后处理）：同任务内利用已发布的充分统计量/树节点重构，严格消耗 0 预算。
  • 优先级 3（工作负载配额）：优先从调用量(25%)、成功率(20%)、渗透率(15%)、占比(10%)、Top-K(10%)中扣除。
  • 优先级 4（机动 Reserve）：任务配额不足时自动向 Reserve 申请补充。
  • 优先级 5（Fail-Closed 阻断）：配额与 Reserve 均耗尽，或导致 Epoch 累计超过 4.0，系统直接阻断发布。
  • 持久化保证：所有 Epoch 记录持久化存储在 SQLite 中，重启服务状态无缝保留，历史 Epoch 绝不覆盖。
